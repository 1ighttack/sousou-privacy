搜搜 · 聚合搜索 — 隐私政策

生效与更新日期：2026 年 10 月 26 日。适用版本：1.6.3。

本政策说明“搜搜 · 聚合搜索”Chrome 扩展如何处理数据。扩展的用途是将用户的一次输入，按所选平台与提示词发送至搜索网站或 AI 网页，并提供分类管理、自动填入、可选自动发送和并排查看。

一、处理哪些数据

  • 配置与输入：用户配置的站点、分类、提示词、选中平台和使用偏好；本次输入以及由模板组合后的内容。默认不持久记住上次输入，用户可主动开启该设置。
  • 当前任务的网页与聊天内容：为定位输入框、核对草稿和判断提交状态，扩展处理所选 AI 页面的相关控件、草稿与可见页面状态。这可能涉及用户选择发送的聊天问题及相关可见聊天内容。
  • 网址与交互：为核对来源、加载状态和正确的并排面板，处理当前任务标签页和子框架的网址。手动“识别”及输入保护会处理当次控件选择、位置和输入交互。扩展不读取浏览器的历史列表，不建立浏览档案或持续按键/点击日志。
  • 视觉 API 密钥：只有用户自行配置视觉 API 时才处理该密钥，保存在本机扩展存储，用于向所配置服务认证请求。扩展不读取 AI 站点的登录密码、登录令牌或 Cookie。
  • 可选截图：视觉识别默认关闭。用户启用、配置服务并授权后，只有默认定位失败需要视觉兜底时，才向该服务发送当前任务的页面或面板截图，以及控件候选的标签与位置。并排模式在本机裁剪后仅传送当前面板。截图可能包含草稿、聊天记录、账号显示信息或其他当时可见内容。

扩展不专门索取身份、健康、财务或位置资料。若用户主动将这类信息输入到问题中，或当前截图中包含这类内容，它们可能作为请求内容被所选网站或 API 处理。

二、数据用于什么目的

数据仅用于用户发起的聚合搜索、提示词组合、当前任务的控件识别、清空与填入、按用户设置提交问题、加载并排面板、保存用户配置，以及防止覆盖用户草稿或重复发送。扩展不内置广告跟踪、行为分析或开发者业务数据收集服务。

三、数据会发送给谁

  • 用户选择的搜索或 AI 网站：用户输入与选中的提示词会交给对应站点。内置平台包括 ChatGPT、DeepSeek、Claude、Gemini、Perplexity、秘塔、Muse、Grok、小米 MiMo、智谱清言、MiniMax、Kimi、千问、点点、腾讯元宝、豆包，以及 Google、Bing、百度、DuckDuckGo、Yandex、Yahoo、360搜索和其他所选搜索网站。用户也可配置自己的搜索地址。
  • 用户配置的视觉 API 服务：仅启用视觉功能时使用。默认接口域名为 api.deepseek.com，用户可更换为兼容的服务。截图、候选控件信息与认证该请求所需的 API 密钥发送至用户配置的服务。使用本机 API 时，这些请求发往用户配置的本机地址。

网站和 API 会按照各自的条款与隐私政策处理收到的内容，可能保留请求或日志。扩展不控制这些服务的保存期限、训练用途或账号政策。浏览器与服务之间的正常请求也可能向该服务提供 IP 地址等连接信息。

扩展不将数据出售给第三方，不用于与聚合搜索无关的广告、画像、信用或贷款判断。分享和传输仅限提供所披露的功能所需。

四、在设备上如何保存

平台配置、提示词、偏好与用户保存的密钥存放在本机 Chrome 扩展存储。密钥按 API 来源绑定，不放入配置导出文件；更换服务来源需重新配置对应凭证。密钥存储限制为扩展可信页面和后台访问，但不宣称使用独立加密保险库。

本次搜索问题与并排会话所需的临时任务状态使用浏览器会话存储，用于执行和恢复流程，在任务清理、会话结束或扩展卸载时清除。处理过的视觉截图仅在本机内存中准备，不由扩展写入图片文件或持久存储；收到截图的外部服务按其政策保存。

用户自行导出的配置文件可能包含自定义网址、提示词和开启记忆后的输入。请自行保管该文件；它不包含扩展单独保存的视觉 API 密钥。

五、权限的使用范围

storage 用于本地配置和会话状态；scripting 用于向已授权的任务网页注入随包提供的适配逻辑；debugger 用于当前任务的原生输入、鼠标点击，以及可选视觉截图，操作结束后断开。它不提供常驻调试服务或任意远程命令入口。

并排功能另申请 webNavigation 与 declarativeNetRequestWithHostAccess：前者核对子框架和加载状态，后者为当前并排标签页内所选 AI 子框架移除 X-Frame-Options 与 Content-Security-Policy 响应头，关闭或离开时清除临时规则。普通标签页不应用这些并排会话规则。

清单的可选 HTTPS 来源支持用户自定义 API 域名，但实际按用户操作请求具体站点授权。本机来源只服务于用户配置的本机视觉 API。扩展未申请 cookies 或 history 权限。

六、用户可以怎样控制和删除

用户可以关闭自动发送、关闭视觉兜底、关闭输入记忆，编辑或删除站点与提示词，并在 Chrome 扩展设置中撤销站点访问授权。卸载扩展可清除该扩展的本机存储，重新安装后需重新配置；自存的配置备份需用户另行删除。外部网站或 API 已收到的数据，需要按照相应服务提供的方式管理和删除。

扩展不自动把剪贴板图片批量上传至 AI。需要图片时，用户应在所选 AI 页面自行粘贴和提交；请在启用视觉识别前确认当前可见内容适合发送至配置的服务。

七、有限使用与政策更新

搜搜对用户数据的使用遵守 Chrome Web Store 用户数据政策，包括有限使用要求；只将数据用于本政策和商店页面披露的聚合搜索功能。若未来增加服务器、日志、分析服务或改变数据用途，将相应更新政策、商店披露及必要的产品内说明。

八、联系

如对本扩展的数据处理有疑问，请通过 Chrome Web Store 本扩展详情页提供的开发者联系入口反馈。第三方 AI、搜索网站及 API 服务的数据处理问题，请联系对应服务提供方。
